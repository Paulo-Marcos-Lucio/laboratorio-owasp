## Política de Segurança

Este repositório é um **laboratório didático** e contém vulnerabilidades de propósito. Não é um produto — não o exponha na internet.

Se encontrar um problema **fora do escopo educativo** (por exemplo, na configuração do build ou do CI), reporte de forma privada para **pmlsp23@gmail.com** com o prefixo `[security]`.
